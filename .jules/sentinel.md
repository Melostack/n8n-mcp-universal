## 2026-08-23 - [SQL Injection via String Interpolation in Limit Clause]\n**Vulnerability:** SQL Injection in `NodeRepository.getAllNodes` where the `limit` parameter was being appended directly to the query string instead of being parameterized.\n**Learning:** Even simple numeric parameters like `limit` should be parameterized to prevent potential injection vulnerabilities if their types are tampered with or miscast before reaching the data access layer. Also learned to avoid checking in unintended lockfile updates when modifying package dependencies locally for tests.\n**Prevention:** Always use parameterized query execution like `this.db.prepare(sql).all(...params)` for all dynamic input regardless of expected type.
