## 2024-06-25 - SQL Injection Vulnerability in Node Repository LIMIT Clause
**Vulnerability:** A SQL injection vulnerability existed in `src/database/node-repository.ts` within the `getAllNodes` method. The `limit` parameter, which might originate from untrusted user input (e.g., via JSON-RPC `args.limit` in MCP endpoints), was being directly interpolated into the SQL query string using a template literal (`sql += \` LIMIT ${limit}\`;`).
**Learning:** Even seemingly benign and structurally expected parameters like `limit` or `offset` can become attack vectors if untrusted input is directly appended to raw SQL queries without proper typing or sanitization. In a context where JSON-RPC arguments are often weakly typed (`any`), it is critical to never trust numerical assumptions.
**Prevention:** Always use proper parameterized bindings (e.g., `?` or named parameters) for all user-provided variables within SQL queries, including `LIMIT` and `OFFSET` clauses. Avoid string concatenation and template literal interpolation when building SQL commands.
