## 2026-06-04 - [Remove sensitive payload logging in HTTP handlers]\n**Vulnerability:** The application was indiscriminately logging `req.body` (which holds parsed JSON parameters) and full `req.headers` objects for incoming requests at the `/mcp` endpoints.\n**Learning:** This exposes sensitive user data, auth tokens, API keys, or large un-sanitized payloads into external log sinks, posing a severe compliance and security risk. This was explicitly logged out in multiple `logger.info` entries using `JSON.stringify(req.body)` and raw header dumps.\n**Prevention:** Substituted complete raw payload and header dumping with Boolean flags (`hasBody`, `hasHeaders`) to confirm request structure without emitting sensitive contents.
