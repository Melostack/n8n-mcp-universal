## 2024-06-08 - SQL Injection via Untyped JSON-RPC Inputs
**Vulnerability:** SQL injection vulnerability in `getAllNodes` method of `NodeRepository`. The `limit` parameter was directly interpolated into the SQL query string using template literals (`` sql += ` LIMIT ${limit}`; ``).
**Learning:** Due to the nature of the Model Context Protocol (MCP) and JSON-RPC, inputs received by the `mcp-tools-engine.ts` (e.g., `args.limit`) are typed as `any`. This bypasses TypeScript's compile-time type checking, allowing an attacker to supply malicious string payloads in place of expected numeric arguments. When these untyped parameters are directly interpolated into database queries, it results in critical SQL injection vulnerabilities.
**Prevention:** Never trust inputs originating from MCP endpoints, even if the TypeScript signature implies a primitive type like `number` further down the call stack. Always use parameterized database queries (e.g., `LIMIT ?`) using `this.db.prepare(sql).all(...params)` to ensure that the database driver properly sanitizes all inputs, regardless of their runtime type.
